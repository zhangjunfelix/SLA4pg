## 1. Pre-Class Preview Guide
### 1.1 Chapter Core Focus
This chapter explores how learners acquire **functional morphology** (grammatical morphemes like -ing, past tense -ed, 3SG -s) in second language (L2) acquisition. It addresses key questions: Do L2 learners follow fixed acquisition orders? Why do they struggle with morphology even if their syntax is intact? And what theories explain these challenges?

### 1.2 Key Learning Objectives
By the end of this chapter, you will be able to:
1. Describe the fixed order of L2 functional morphology acquisition and how it relates to L1 patterns.
2. Distinguish between "syntax-before-morphology" and "morphology-before-syntax" views.
3. Compare major hypotheses (RDH, MSIH, PTH, FRH) explaining L2 morphology challenges.
4. Analyze learner data to identify syntax-morphology dissociation and prosodic transfer effects.
5. Explain how universal features are "reassembled" for L2 functional morphology.

### 1.3 Preview Questions (To Guide Reading)

- What is "prosodic transfer," and how does it affect L2 morphology production?

## Preview & Scaffolding 

### 1. Why This Preview Matters  
Chapter 7 ties 3 areas together:  
- **Morphology**: Small word parts (e.g., *-ed*, *-s*).  
- **Syntax**: Sentence structure (e.g., subject-verb order).  
- **Meaning**: What you want to convey (e.g., past time).  

This preview clarifies the basics so theories make sense later.


### 2. Key Morphology Types  
Chapter 7 focuses on **inflectional morphology** (grammar markers)—not derivational (word-creators).  

| Type               | What It Does                  | Examples                          |
|---------------------|--------------------------------|-----------------------------------|
| Derivational        | Makes new words/word classes   | *teach* → *teacher*, *happy* → *unhappiness* |
| Inflectional (focus) | Adds grammar info (no new word) | *walk* → *walks*, *cat* → *cats*  |


### 3. Functional vs. Lexical Morphemes  
Functional morphemes = **grammar glue** (no standalone meaning); lexical = **content words** (carry ideas).  

| Type       | Function                          | Examples                  | What It Adds                |
|------------|-----------------------------------|---------------------------|-----------------------------|
| Lexical    | Conveys concepts (objects/actions)| *dog*, *run*, *beautiful*  | “What” is happening/being   |
| Functional | Signals grammar relationships    | *-ed*, *-s*, *the*, *if*   | “When”/“how”/“which one”   |

#### Example  
- *She walked the dog*:  
  - Lexical: *walked* (action), *dog* (object).  
  - Functional: *-ed* (past time), *the* (specific dog).  


### 4. Core Functional Morpheme Categories  
These are the “grammar tools” Chapter 7 discusses—each links to a syntax “slot” (e.g., Tense Phrase).  

| Category       | Example       | Job                                  | Syntax Link               |
|----------------|---------------|---------------------------------------|---------------------------|
| Tense/Aspect   | *-ed*, *-ing* | Marks when an event happens           | Tense Phrase (TP)         |
| Agreement      | *-s* (3SG)    | Makes subject/verb “match” (e.g., *he walks*) | Agreement Phrase (AgrP) |
| Determiners    | *a*, *the*    | Marks if a noun is specific           | Determiner Phrase (DP)    |
| Complementizers | *that*, *if*  | Links clauses (e.g., *I think that she left*) | Complementizer Phrase (CP) |


### 5. Syntax–Morphology–Meaning: How They Work Together  
Grammar is a 3-layer system—learners often master the first two before the third.  

| Layer          | What It Does                          | Example Step                          | L2 Common Error                          |
|----------------|---------------------------------------|---------------------------------------|------------------------------------------|
| 1. Meaning     | Convey your idea (e.g., past action)  | “I ate lunch earlier.”                | None—idea is clear.                      |
| 2. Syntax      | Organize words (correct order)        | *I eat lunch earlier*                 | Word order is right.                     |
| 3. Morphology  | Add grammar markers (surface form)    | *I **ate** lunch earlier*             | *I eat lunch earlier* (missing *-ed*).   |

→ Errors usually happen at Layer 3 (morphology)—not meaning/syntax.


### 6. Functional Categories (Syntax “Slots”)  
These are invisible “slots” in sentences that functional morphemes fill (e.g., TP = tense slot).  

| Category | What It Does                          | Example Sentence Link                |
|----------|---------------------------------------|---------------------------------------|
| T (Tense)| Marks time (past/present)             | *She **walks*** (present)             |
| Agr (Agreement)| Makes subject/verb match         | *He **likes*** (3SG subject → *-s*)   |
| D (Determiner)| Marks specific/non-specific       | ***The** cat* (specific cat)         |


### 7. The Big Chapter 7 Question  
Chapter 7 debates: **Does syntax (structure) come before morphology (form)?**  

| View                  | Core Claim                                  | Example Prediction                          |
|-----------------------|---------------------------------------------|---------------------------------------------|
| Syntax-before-morphology | Structure first, form later              | *He walk* = knows TP (needs subject/tense) but misses *-s*. |
| Morphology-before-syntax | Form first, structure later              | *He walk* = no TP yet (no tense/agreement slot). |

Chapter 7 mostly supports **syntax-before-morphology** (e.g., Patty uses overt subjects but omits *-s*).


### 8. Key Term Cheat Sheet  
| Term                  | Simple Definition                          |
|-----------------------|--------------------------------------------|
| Interpretable Feature | Adds meaning (e.g., [past] = “before now”) |
| Uninterpretable Feature | Grammar-only (e.g., *-s* = subject-verb match) |
| Mapping               | Linking abstract grammar to surface form   |


### 9. Chapter 7 Roadmap  
You’ll learn 4 theories to explain L2 morphology errors:  
1. RDH: Missing grammar “slots” (e.g., no agreement).  
2. MSIH: Intact slots, but can’t retrieve the form (e.g., forget *-ed*).  
3. PTH: L1 rhythm affects form (e.g., stressing *THE*).  
4. FRH: Need to “rearrange” grammar features (e.g., L1 vs. L2 tense markers).

Each section includes **Key Takeaways**, **Core Concepts & Evidence**, and **Key Study Examples** to simplify preview and review.

### Section 7.1: Morpheme Studies  
#### Key Takeaways  
L2 functional morphology has a (mostly) fixed acquisition order, but early studies overlooked L1 transfer and overuse errors—revised methods (e.g., Stauble’s accuracy) give a more realistic view of "mastery."

#### Core Concepts & Evidence  
1. **Foundational L1 Precedent: Brown’s (1973) Functor Order**  
   - Brown tracked 3 English L1 children and found 14 functional morphemes (e.g., -ing, plural -s) are acquired in a fixed order:  
     *Progressive -ing (19–28 months) → prepositions in/on (27–33 months) → plural -s (27–33 months) → 3SG -s (28–50 months)*.  
   - Order depends on **complexity** (fewer grammatical features = earlier) and **phonetic salience** (easier to perceive = earlier).  

2. **L2 Morpheme Order: Creative Construction Hypothesis**  
   - Dulay & Burt (1973, 1974): Spanish/Chinese L1 children learning English showed the same accuracy order (high for -ing/plural -s, low for possessive ’s/3SG -s)—even with different L1s, proving innate grammar (not just L1 transfer) guides acquisition.  
   - Bailey et al. (1974): Adults follow the same order as children (e.g., -ing early, 3SG -s late)—fixed order is a general L2 pattern.  

3. **Criticisms & Method Improvements**  
   - Early flaws: Ignored L1 transfer (e.g., Spanish L1 learners master plural -s faster than Japanese L1 learners, as Spanish has plural morphology) and overuse errors (e.g., using -ing for imperatives like *Sitting down!*).  
   - Stauble’s (1984) revised accuracy: Includes overuse in calculations (denominator = obligatory contexts + overused contexts) to avoid overestimating mastery.  

4. **"Acquired" Cutoff Debates**  
   No universal standard—each reflects a theory:  
   - 90% correct (Brown): Measures "full adult-like mastery."  
   - 60% correct: Signals "emerging grammar" (above chance).  
   - First productive use: Marks when a structure enters the learner’s grammar.  

#### Key Study Example  
- **Dulay & Burt (1973) BSM Task**: 5–8-year-old Spanish L1 children with varying English exposure (Sacramento = high, East Harlem = low) all showed congruent accuracy: 85% for -ing, 30% for possessive ’s—proving fixed order.  


### Section 7.2: Syntax-before-morphology  
#### Key Takeaways  
L2 learners acquire the **syntax of functional categories** (e.g., obligatory subjects, tense meaning) first—morphology gaps reflect surface mapping issues, not broken syntax.

#### Core Concepts & Evidence  
1. **Competing Views**  
   - **Morphology-before-syntax**: Learners need surface morphology (e.g., 3SG -s) to "activate" syntax (e.g., TP structure) (Vainikka & Young-Scholten).  
   - **Syntax-before-morphology (White 2003)**: Learners master syntactic properties (e.g., overt subjects) first; morphology lags due to mapping challenges (not lack of syntax).  

2. **Empirical Evidence for Syntax-Morphology Dissociation**  
   - **Lardiere’s (1998a,b) Patty Case**: Mandarin L1 adult L2 English learner with 4.5% accuracy for 3SG -s and 34.5% for past -ed—but 98% overt subjects and 100% nominative case. Her intact syntax proves she has a functional TP; low morphology is a surface issue.  
   - **Li’s (2012) Child Learners**: Mandarin L1 children L2 English show 16% accuracy for 3SG -s but 100% overt subjects—same dissociation as adults.  

3. **Semantic Support**  
   - Slabakova (2003): Bulgarian L1 learners (no L1 tense-aspect morphology) mastered English aspect meanings (e.g., progressive = ongoing) despite poor morphology—proving semantic/syntactic knowledge comes first.  

#### Key Study Example  
- **Patty’s TP Performance**: She correctly uses overt subjects (*He takes the bus*, not *Takes the bus*) and nominative case (*he* vs. *him*) but omits 3SG -s (*He take*). This shows her TP syntax is intact—morphology is the only gap.  


### Section 7.3: Representational Deficit Hypothesis (RDH)  
#### Key Takeaways  
RDH argues L2 morphology errors reflect **deep syntactic deficits** (missing/unvalued features), not just surface issues—but it fails to explain partial accuracy and syntax-morphology dissociation.

#### Core Concepts & Evidence  
1. **RDH Core Claim**  
   Adult L2 learners cannot fully acquire abstract morphosyntactic features absent in their L1. Morphology errors (e.g., missing past -ed) mean the associated syntactic category (e.g., TP) is impaired.  

2. **RDH Variants**  
   | Variant | Core Claim |  
   | --- | --- |  
   | Valueless Features Hypothesis (Eubank) | L2 features (e.g., agreement) are "inert" and can’t trigger syntax. |  
   | Failed Functional Features Hypothesis (Hawkins & Chan) | Learners can’t reset L1 parameters (e.g., null subjects). |  
   | Interpretability Hypothesis (Hawkins et al.) | Only meaning-linked features (e.g., noun gender) are acquirable—syntax-only features (e.g., adjective gender concord) are not. |  

3. **Supporting Evidence**  
   - **Hawkins & Liszka (2003)**: Chinese L1 learners (no L1 tense morphology) have 63% past -ed accuracy, while German/Japanese L1 learners (with L1 tense) have 92%—RDH attributes this to impaired TP in Chinese learners.  
   - **Franceschina (2001, 2005)**: English L1 L2 Spanish learner Martin has 95% accuracy for noun gender (meaning-linked) but 60% for gender concord (syntax-only)—aligns with Interpretability Hypothesis.  

4. **Limitations**  
   - Can’t explain partial accuracy (e.g., 63% past -ed—if TP is impaired, accuracy should be random).  
   - Ignores syntax-morphology dissociation (e.g., Patty’s intact TP syntax).  

#### Key Study Example  
- **Martin’s Gender Performance**: He correctly assigns gender to nouns (*el perro* = "the dog") but struggles with adjective concord (*el perro negra* instead of *negro*). RDH argues this is because noun gender is meaning-linked (acquirable), while concord is syntax-only (unacquirable).  


### Section 7.4: The Missing Surface Inflection Hypothesis (MSIH)  
#### Key Takeaways  
MSIH rejects representational deficits—L2 learners have **intact syntax** but struggle to map abstract features to surface morphology (e.g., retrieving -s for [3SG] features).

#### Core Concepts & Evidence  
1. **MSIH Core Claim**  
   Morphology is "missing on the surface, not in the syntax." Learners know syntactic features (e.g., [3SG, present]) but fail to retrieve the corresponding morphology (e.g., -s) during production.  

2. **Empirical Evidence**  
   - **Haznedar & Schwartz (1997) Erdem Case**: Turkish L1 L2 English child (4–5 years) uses 90% overt subjects (syntactic finiteness) but 85% uninflected verbs—proves he understands finiteness; morphology retrieval is the issue.  
   - **Prévost & White (2000a,b) Adult Learners**: L2 French/German learners use infinitives in finite positions (e.g., *je manger* instead of *je mange*) but avoid finite verbs in non-finite positions—shows they know finiteness rules; they just default to easier-to-retrieve infinitives.  

3. **Mechanism: Distributed Morphology**  
   Syntax is built first (with features like [3SG]); lexical items (e.g., -s) are inserted late. L2 learners may insert default forms (e.g., infinitive *take*) if the target (e.g., *takes*) is inaccessible.  

4. **Teaching Relevance**  
   Focus on **automatic retrieval**: Drill high-frequency inflections (e.g., 3SG -s) in context to reduce retrieval load.  

#### Key Study Example  
- **Erdem’s Development**: Early on, he says *I play* (overt subject = good syntax) but not *I playED* (missing morphology). Later, his morphology accuracy rises to 60%—proving retrieval improves with practice, not syntax.  


### Section 7.5: The Prosodic Transfer Hypothesis (PTH)  
#### Key Takeaways  
PTH adds that L2 morphology gaps come from **L1 prosodic transfer**—learners apply L1 rules for stress/word structure to L2, misaligning with L2’s prosodic requirements.

#### Core Concepts & Evidence  
1. **Prosodic Structure Basics**  
   Phonology is hierarchical: *Segments → Syllables → Feet → Prosodic Words (PWd) → Phonological Phrases*. Languages differ in how they attach morphology to these levels (e.g., English -ed is "adjoined" to PWd; Mandarin aspect markers are "integrated" in PWd).  

2. **Supporting Evidence**  
   - **Goad & White (2008) Articles**: Mandarin/Turkish L1 L2 English learners stress articles (*THE book*, *A mat*)—transferring L1 prosody (Mandarin has no unstressed words; Turkish stresses definite markers).  
   - **Goad & White (2006) Past Tense**: Mandarin L1 learners produce -ed with non-native strong release (e.g., /t/ for *played*)—transferring Mandarin’s prosodic prominence rules.  

3. **PTH vs. MSIH**  
   They complement each other: MSIH explains retrieval gaps; PTH explains position/phonetic errors (e.g., omitting articles after disyllabic verbs like *catches [the] mat*).  

#### Key Study Example  
- **Mandarin L1 Article Stress**: Learners say *THE cat* (stressed *the*) because Mandarin has no unstressed function words—this is prosodic transfer, not lack of article knowledge (they use *the* correctly in strong positions).  


### Section 7.6: The Feature Reassembly Hypothesis (FRH)  
#### Key Takeaways  
FRH argues L2 morphology acquisition is about **reassembling universal features** (not learning new ones)—learners adapt L1 feature bundles to L2’s category/form-meaning mappings.

#### Core Concepts & Evidence  
1. **FRH Fundamentals**  
   All languages use universal features (e.g., [past], [gender]). L2 learners:  
   1. Identify which features L2 uses.  
   2. Map features to L2’s lexical category (e.g., [past] on verbs in English, complementizers in Irish).  
   3. Learn L2’s form-meaning links (e.g., -ed = [past] + [perfective]).  

2. **Form-Meaning Mismatches: English -ed**  
   Lardiere (2005, 2007) shows -ed encodes 4 meanings (e.g., [+past] = *We devoured*; politeness = *I was wondering*). Learners acquire them incrementally (core first, then secondary).  

3. **Cross-Linguistic Category Mismatches**  
   | Language | [past] Feature Host | Form | L2 Challenge |  
   | --- | --- | --- | --- |  
   | English | Verb | -ed | Mandarin L1: Map [past] to verbs. |  
   | Irish | Complementizer | gurL | English L1: Map [past] to complementizers. |  

4. **Supporting Evidence: Shimanskaya (2015)**  
   English L1 L2 French learners:  
   - Beginners transfer L1 [Human] (he/she = [+Human], it = [–Human]) to French clitics (le/la = no [Human]), making gender errors for inanimates.  
   - Advanced learners drop [Human] and use French’s [gender]-only system (99% accuracy)—proving reassembly.  

#### Key Study Example  
- **French Clitic Reassembly**: Advanced learners correctly use *la* for both [+Human] (*la fille*) and [–Human] (*la table*)—they reassembled from L1’s [Human]+[gender] to L2’s [gender]-only bundle.  


## 3. Post-Class Review Tools
### 3.1 Chapter Takeaways Summary  
1. L2 functional morphology has a fixed order, but L1 transfer and overuse errors modify it.  
2. Syntax develops before morphology—low morphology accuracy ≠ broken syntax.  
3. RDH (deficits) vs. MSIH (retrieval) vs. PTH (prosody) vs. FRH (reassembly): Together, they explain most L2 morphology gaps.  
4. Reassembly of universal features is key for advanced L2 morphology mastery.

### 3.3 Quick Reference: Hypothesis Comparison  
| Hypothesis | Core Explanation for Morphology Gaps | Key Strength | Key Weakness |  
| --- | --- | --- | --- |  
| RDH | Impaired syntactic features (absent in L1) | Explains L1 transfer effects | Ignores syntax-morphology dissociation |  
| MSIH | Surface retrieval of morphology | Aligns with syntax-before-morphology evidence | Doesn’t explain prosodic errors |  
| PTH | L1 prosodic transfer | Explains position/phonetic errors | Focuses only on production |  
| FRH | Reassembling universal features | Accounts for cross-linguistic variability | Needs more data on beginner reassembly |
