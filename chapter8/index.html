    1. Pre-Class Preview Guide #

    1.1 Chapter Core Focus #

    This chapter explores the acquisition of syntax (sentence structure and grammatical dependencies) in second language (L2) learning, with a focus on three core themes: how the concept of “syntactic parameters” has evolved, whether L2 learners develop native-like syntactic representations, and how cross-linguistic differences (e.g., word order, verb movement, wh-movement) shape acquisition.

    1.2 Key Learning Objectives #

    By the end of this chapter, you will be able to:

    1. Trace the historical evolution of the “parameter” concept—from early “binary switches” to modern feature-based models.
    2. Distinguish between Representational Deficit and Full Functional Representation accounts of L2 syntax acquisition.
    3. Analyze how L2 learners acquire cross-linguistic word order differences (e.g., SVO vs. SOV) and verb movement patterns (e.g., French vs. English).
    4. Explain universal constraints on wh-movement (island constraints) and their role in testing Universal Grammar (UG) access in L2.
    5. Interpret empirical data to evaluate which theoretical frameworks best explain L2 syntax acquisition.

    1.3 Preview Questions (To Guide Reading) #

    • Why did early “parameter switch” models fail to explain L2 syntax acquisition?
    • What evidence supports the claim that L2 learners can develop native-like syntactic representations (Full Functional Representation)?
    • How do L1 transfer and UG interact in L2 word order acquisition (e.g., Greek SVO → Turkish SOV)?
    • Why do French L1 learners of English struggle with question formation even after mastering adverb placement?
    • What are “island constraints,” and how do they prove UG access in L2 wh-movement acquisition?

    Section 8.1: A Historical Excursion into the Notion of Parameter #

    Key Takeaways #

    The concept of “syntactic parameters” (language-specific variation) has evolved from “binary switches” (triggering clusters of constructions) to lexically encoded feature bundles (per the Minimalist Program). Early models failed empirically, while modern frameworks focus on incremental feature reassembly.

    Core Concepts & Evidence #

    1. Early Parameter Model (1980s–1990s): Binary Switches & Clusters

      • Core Idea: Parameters are on/off switches paired with universal principles (e.g., Subjacency). A single switch setting triggers a “cluster” of related constructions (like a light switch controlling multiple lights).
      • Flagship Example: Null Subject Parameter (NSP) (Rizzi 1982):
        • Spanish (NSP = On): Allows null subjects (Mangia come una bestia = “He/she eats like a beast”), null expletives (Piove oggi = “It rains today”), and postverbal subjects (Ha telefonato uno studente = “A student called”).
        • English (NSP = Off): Prohibits these constructions (e.g., *Eats like a beast is ungrammatical).

    2. Empirical Failures of Early Models

      • L2 NSP Studies (White 1985, Hilles 1986): Spanish L1 learners of English mastered postverbal subjects but still produced null subjects—contradicting the “cluster” prediction (if one NSP construction is mastered, all should be).
      • Verb Movement Parameter (White 1990): Francophone L2 English learners mastered adverb placement (e.g., John often kisses Mary) but failed at question formation (e.g., *Likes she John?), proving no cluster acquisition.

    3. Modern Reconceptualization (2000s–Present): Feature-Based Parameters

      • Core Idea: Parameters are not switches but universal feature bundles on lexical items (e.g., verbs, complementizers). Languages differ in which features they select and which lexical category hosts them.
      • Example: Tense feature [past] is universal but encoded on:
        • Verbs (English: walked).
        • Complementizers (Irish: gurL thuig sé = “that-Past understood he”).
        • Nouns (Somali: árdday-gii = “student-Det.Masc.Past” = “former student”).

    4. Current Thinking: Cognitive Primitives & Sentence Domains

      • Ramchand & Svenonius (2014) propose a cross-linguistically fixed sentence hierarchy linked to cognition:
        1. Verb Domain (V): Encodes the action/state (e.g., Mary eat a sandwich).
        2. Tense Domain (T): Anchors the event in time (e.g., Mary ate a sandwich).
        3. Complementizer Domain (C): Links the sentence to discourse (e.g., Did Mary eat a sandwich?).

    Key Study Example #

    • White (1985) NSP Study: Spanish L1 learners of English accepted null subjects 40% of the time (vs. 80% accuracy for French L1 learners) but mastered postverbal subjects—proving NSP does not act as a single switch.

    Section 8.2: Representational Deficit vs. Full Functional Representation #

    Key Takeaways #

    Two frameworks debate L2 syntactic representations: Representational Deficit argues L2 learners have permanent gaps (uninterpretable features absent in L1 cannot be acquired), while Full Functional Representation claims learners develop native-like representations (errors stem from surface performance, not defective syntax).

    Core Concepts & Evidence #

    1. Representational Deficit Accounts

      • Core Claim: Adult L2 learners lack access to some universal features—uninterpretable features (regulate syntax, e.g., adjective gender concord) absent in L1 are permanently unacquirable.
      • Key Variants:
        • Fundamental Difference Hypothesis (Bley-Vroman): Learners rely on domain-general strategies (not UG) and L1 transfer—native-like syntax is impossible.
        • Interpretability Hypothesis (Hawkins et al.): Only meaning-linked (interpretable) features (e.g., noun gender) are acquirable; syntax-only features are not.
      • Example (Tsimpli & Dimitrakopoulou 2007): Greek L1 learners of English still accepted ungrammatical resumptive pronouns (*Who do you think that Susan would marry him?) at advanced stages—claimed as proof of permanent deficit.

    2. Full Functional Representation Accounts

      • Core Claim: L2 learners have intact syntactic representations—errors come from surface issues (e.g., feature mapping, lexical retrieval), not defective syntax.
      • Key Variants:
        • Full Transfer Full Access (FTFA, Schwartz & Sprouse): Learners transfer L1 features initially but retain UG access to reset parameters.
        • Missing Surface Inflection Hypothesis (MSIH, Prévost & White): Syntax is intact; morphology gaps reflect mapping challenges (e.g., Patty’s 4.5% 3SG -s accuracy but 98% overt subject accuracy, Lardiere 1998a,b).
      • Example (Leal Méndez & Slabakova 2014): Advanced French L1 learners of English rejected ungrammatical [Human] pronoun errors (*It is Mary) at 92% accuracy—matching natives (96%), proving no permanent deficit.

    Section 8.3: Word Order #

    Key Takeaways #

    L2 word order acquisition starts with L1 transfer but progresses to L2 norms via UG. Canonical orders (e.g., Turkish SOV) are acquired early, while non-canonical orders (e.g., Turkish OSV) require integrating multiple features (word order + case + specificity)—slowing progress.

    Core Concepts & Evidence #

    1. Cross-Linguistic Word Order: Prevalence & Cognitive Roots

      • Typological Dominance: SVO (~35.4%, e.g., English) and SOV (~45%, e.g., Turkish) dominate because they align with human cognition (Agent → Action → Patient).
      • Rare Orders: VSO (e.g., Irish) and OSV are rare—L2 acquisition is slower due to cognitive dissonance.

    2. Theoretical Evolution of Word Order

      • 1980s: VP Headedness Parameter: SVO = head-initial VP (verb before object); SOV = head-final VP (verb after object).
      • 1990s (Kayne 1994): Universal SVO: All languages have underlying SVO—SOV results from object movement to pre-verbal position.
      • 2000s+: Lexical Diacritics: Verbs carry diacritics (e.g., English eat = [+pre-object]; Turkish yemek = [+post-object])—L2 learners acquire these to produce correct order.

    3. L2 Word Order Acquisition: Transfer & UG

      • Early Transfer (FTFA): Greek L1 (SVO) learners of Turkish (SOV) initially produce SVO (Mary yedi bir elma = “Mary ate an apple”) but shift to SOV (Mary bir elma yedi) with input (Papadopoulou et al. 2011).
      • Feature Interaction Challenge: Non-canonical orders (e.g., Turkish OSV: Bir elma Mary yedi = “An apple Mary ate”) require integrating word order, Accusative case (-i), and specificity—intermediate learners have 49% case accuracy (vs. 95% verbal inflection), limiting OSV mastery.

    Key Study Example #

    • Papadopoulou et al. (2011) Greek-Turkish Study: Beginners mastered Turkish SOV (canonical order) but failed at OSV (non-canonical, needs case + specificity). Advanced learners improved OSV accuracy to 72%—proving incremental feature integration.

    Section 8.4: Verb Movement #

    Key Takeaways #

    Verb movement (verbs moving to Tense/Complementizer vs. staying in Verb Phrase) is not a parametric switch—L2 acquisition involves incremental feature mapping. The Verb-Second (V2) rule (German) is acquired late due to rare input but mastered by advanced learners.

    Core Concepts & Evidence #

    1. Cross-Linguistic Verb Movement: French vs. English

      • French: Verbs move to Tense (T)/Complementizer (C)—supports verb-adverb (S-V-Adv-O: Jean embrasse souvent Marie), verb-negation (S-V-Neg-O: Marie n’aime pas Jean), and question inversion (V-S-O: Aime-t-elle Jean?).
      • English: Verbs stay in Verb Phrase (VP)—requires adverb before verb (S-Adv-V-O: John often kisses Mary), do-support for negation/questions (S-Aux-Neg-V-O: Mary does not like John).

    2. Early Verb Movement Parameter: Failed Cluster Predictions

      • White (1990) Francophone L2 English Study: Learners taught adverb placement showed no improvement in question formation—proving no cluster acquisition (undermines “switch” model).

    3. Verb-Second (V2) Rule: German Case Study

      • V2 Rule: Finite verbs must be the second constituent in German main clauses (e.g., Im Park hat er sie gefunden = “In the park had he her found”).
      • L2 Acquisition:
        • Beginners: 49.3% V2 violations (e.g., *Im Park er hat sie gefunden = “In the park he had her found”).
        • Advanced: 100% accuracy (Conradie 2006)—explained by Yang’s Variational Learning Model (rare unambiguous V2 input: 1.2% of child-directed speech) and Multiple Grammars Hypothesis (coexisting L1/L2 subgrammars).

    Key Study Example #

    • Conradie (2006) Afrikaans V2 Study: South African English L1 learners of Afrikaans (V2 language) showed 100% V2 accuracy at advanced stages—proving UG access to complex verb movement.

    Section 8.5: Wh-movement #

    Key Takeaways #

    Wh-movement (wh-phrases moving to clause start) is constrained by universal “island rules” (prohibiting movement out of certain structures). L2 learners acquire these constraints via UG—proving Full Functional Representation, even if L1 lacks wh-movement.

    Core Concepts & Evidence #

    1. Cross-Linguistic Wh-movement: In-situ vs. Movement

      • Wh-movement Languages (English): Wh-phrases move to CP (e.g., What did John buy?; *John bought what? is ungrammatical for regular questions).
      • Wh-in-situ Languages (Mandarin): Wh-phrases stay in base position (e.g., Hufei mai-le shenme? = “Hufei bought what?”).

    2. Island Constraints: Universal Limits

      • Island types (prohibit wh-movement out of bounded structures):
        • Wh-islands: *Who did you wonder whether this girl danced with?
        • Complex NP islands: *Who did you spread a rumor that this girl danced with?
      • Poverty of the Stimulus: Learners never hear ungrammatical island sentences—acquiring constraints proves UG access.

    3. L2 Wh-movement: Evidence for UG

      • Martohardjono (1993): Chinese/Indonesian L1 learners of English rejected strong island violations (87%/76% accuracy) more than weak ones—mirroring natives (99%/78% accuracy), proving UG access.
      • Li (1998): Chinese L1 learners in China (classroom input) and Canada (naturalistic input) had comparable island constraint accuracy—input type does not block UG use.

    Key Study Example #

    • Johnson & Newport (1991) Chinese L1 Study: Adult Chinese L1 learners of English reliably distinguished grammatical (non-island) and ungrammatical (island) wh-movement—accuracy above chance, proving Subjacency acquisition via UG.

    3. Post-Class Review Tools #

    3.1 Chapter Takeaways Summary #

    1. Parameters evolved from “switches” to feature bundles—L2 acquisition involves incremental feature reassembly, not holistic switch-setting.
    2. Full Functional Representation better explains L2 syntax: Learners develop native-like representations; errors are surface issues (not deficits).
    3. Word order/verb movement acquisition starts with L1 transfer but progresses via UG—complexity rises with feature interaction.
    4. Wh-movement island constraints are acquired via UG—proof of innate syntactic principles in L2.

    3.2 Self-Check Questions #

    1. Why did early parameter models (e.g., NSP cluster) fail to explain L2 syntax acquisition?
    2. How does Patty’s case (Lardiere 1998a,b) support Full Functional Representation?
    3. What makes Turkish OSV (non-canonical word order) harder to acquire than SOV (canonical)?
    4. Why is German V2 acquired late by L2 learners (per Yang’s model)?
    5. How do island constraints prove UG access in L2 wh-movement acquisition?
