    Week 2 — Language Variation & the Learning Task" #

    Anchor text: Slabakova, R. (2016). Second Language Acquisition. Chapter 2: Language variation.
    Link to Chapter 2

    ⭐ Overview #

    • How languages differ and what that means for learning a second language.
    • Where variation “lives” in the grammar today (hint: features in the functional lexicon) and why that matters for learners.
    • How prior knowledge from the L1 transfers into the L2 starting point, and what “resetting” involves.
    • Why some areas (e.g., functional morphology and mismatched feature cues) tend to be harder.

    🎯 Learning goals #

    By the end of Week 2 you should be able to:

    1. Explain (in plain language) where many cross-language differences come from.
    2. Describe the idea of L1 transfer as the initial state and what it predicts.
    3. Give one concrete example of how a feature mapping/mismatch can make learning harder.
    4. Sketch a simple “if…then” prediction for learner behavior based on a parametric difference.

    📖 Reading (do before class) #

    • Required: Slabakova (2016), Chapter 2 (focus on §§2.1–2.4 big picture).
    • As you skim: note any places where the book connects variation → specific learning tasks.

    Guiding questions while you read

    • Where does the chapter locate most variation today (lexicon? interfaces?) and why?
    • If your L1 and L2 differ on some feature (e.g., subject expression, word order), what prediction would that make for early L2?

    🧠 Key terms #

    principles & parameters; Minimalist Program; functional lexicon; grammatical features; PF/LF interfaces; transfer; parameter “resetting”; feature exponents; clustering; compounding parameter; learning task

    🧩 Core content (gentle, big-picture) #

    1) From “big switches” to features in the functional lexicon #

    • Early accounts treated parameters like global on/off switches (e.g., a single “Null Subject” setting predicting a whole cluster of properties). That idea was useful but often too coarse for the cross-linguistic facts.
    • A modern, learner-friendly view: many differences live in the features of functional items (determiners, tense/aspect heads, complementizers, etc.). Learning an L2 means learning which features exist and how they are expressed in that language.
    • Friendly example: Word order differences (e.g., adjective position) often follow from features on functional heads (e.g., N vs. A movement triggers). What felt like a “big switch” is better seen as a few specific feature settings.
    • Try it: Take a simple contrast you know (e.g., subject pronoun use, adjective position). Note the functional word(s) involved and guess which feature might be different (e.g., [+definite], [+topic], [+EPP]).

    2) What are “features” (in plain words)? #

    • Think of features as tags of grammatical information attached to functional elements: number, gender, definiteness, person, tense, aspect, case, etc.
    • Crucial point: Languages share meanings but differ in how they signal them (which feature bundles, where they appear, and whether they must be overt).
    • Mini mapping examples:
      • Definiteness: English uses the article the; some languages rely more on word order or context instead of an article.
      • Tense/Aspect: English often marks tense on the verb; other languages distribute aspect across particles or verb classes.
      • Number/Classifiers: English plurals (cats); classifier languages may omit plural marking with numerals and use a classifier instead.
    • Try it: Pick one L2 morpheme you find tricky (e.g., articles). Ask: Which feature(s) is this morpheme carrying here? Is the same meaning split across multiple forms in my L2?

    3) Feature exponents and cue reliability #

    • One feature can have many forms (one-to-many), and one form can realize several features (many-to-one). This can make cues less reliable for learners.
    • Examples of cue complexity:
      • English -s can be plural (cats) or 3sg agreement (runs)—same form, different features.
      • Aspect in some languages maps to periphrastic forms (auxiliaries + participles) rather than a single suffix.
    • What this means for learners: When cues are distributed or ambiguous, learners need extra practice to stabilize form–meaning mappings.
    • Quick diagnostic: Given 6 L2 sentences with the same meaning, highlight the different forms used; which mapping is most/least consistent?

    4) L1 transfer as the starting point #

    • A practical default: your L1’s feature settings are your initial L2 settings. Early L2 behavior reflects positive transfer (helpful similarities) and negative transfer (overusing an L1 option that the L2 restricts).
    • Friendly predictions:
      • Null subjects: If L1 licenses silent subjects, beginner L2 English may show more dropped subjects.
      • Articles/definiteness: If L1 lacks articles, L2 English learners may over/underuse a/the until feature mappings settle.
      • Word order: If L1 allows more flexible order, learners may initially misplace adverbs/topics in L2.
    • Try it: Write one if-then statement from your L1/L2 pair: “If L1 has X, then early L2 may show Y.”

    5) Where learning gets tough (and why) #

    • Functional morphology: Small endings or particles often carry multiple features and interact with syntax/semantics, making them a common bottleneck.
    • Feature reassembly: Learners may have the right meanings but must re-package them using L2-specific forms (e.g., English articles vs. bare nouns with classifiers).
    • Interface load: When meanings depend on structure + context (syntax–semantics, syntax–pragmatics), learners must coordinate multiple systems under time pressure.
    • Processing cost: Less frequent or less reliable cues require more attention and working memory, slowing stabilization.

    6) Friendly examples you can visualize #

    • Null subjects: Some languages allow pronoun drop in certain contexts; English typically doesn’t → early omission is predictable for some learners.
    • Articles/definiteness: English demands a/the where other languages use context—expect over/underuse patterns before stabilization.
    • Gender agreement: If L1 lacks grammatical gender, L2 gender marking may show late stabilization (especially with low-salience endings).
    • Tense/Aspect: Learners may conflate habitual vs. completed events if L1/L2 carve up aspect differently.
    • Compounding & resultatives: Some languages productively allow N+N compounds and resultative constructions; others restrict them—useful for order-of-difficulty predictions.

    7) Simple diagnostics (low-stress, class-ready) #

    • Minimal pair sort: Give pairs differing by a single feature (e.g., the cat vs. a cat). Ask learners to sort by meaning/use; discuss the feature behind the contrast.
    • Cloze with choices: Provide short texts where a feature is realized in different ways (articles, aspect). Have learners choose the most natural option and justify the feature logic.
    • Judgment strip: 8–10 short sentences targeting one feature (some well-formed, some not). Quick acceptable/unacceptable ticks → look for pattern, not perfection.
    • Production nudge: Prompts eliciting the target feature (e.g., describing pictures to force reference tracking or aspect choices).

    8) What success looks like (for Week 2) #

    • You can name a cross-language difference and locate it as a feature mapping (not just “grammar is different”).
    • You can write a clear if-then prediction from that difference.
    • You can propose a tiny check (sorting, cloze, judgments, or a short production prompt) that would confirm or challenge your prediction.

    ✅ Tasks #

    Before class (preview) #

    • Read Ch. 2 for the main ideas (don’t get lost in technical terms).
    • Bring one L1 ↔ L2 difference you’ve noticed (word order? subject expression? compounding?). We’ll use it to make a prediction.

    In class (light activities) #

    • Feature hunt (pairs, 8–10 min): Pick one L1↔L2 contrast and say which feature(s) might be different and how they surface.
    • If-then postcards (small groups, 10 min):
      • Write one sentence: “If L1 has X, then beginners may Y in L2.”
      • Keep it observable (Y should be something you can count or notice).

    Practice (micro-lab you can try) #

    Prompt (approachable): “If a learner’s L1 freely drops subjects but the L2 does not, early L2 subject omission should be higher for that learner group.”

    • Design idea: Compare a few beginner sentences (two L1 groups). Count subject present/absent.
    • What would falsify it? No group difference; or consistent subjects from the start.
      (This mirrors how Chapter 2 turns theory into learning tasks and predictions.)

    After class (review) #

    1. Mini reflection (≈150–200 words):

      • Name one L1↔L2 difference in features or feature exponents.
      • Write an if-then prediction it suggests.
      • One easy way you could check it (e.g., quick corpus search; classroom samples).

    2. Self-check (answers hidden):
      (1) Where does the Minimalist view largely locate variation?

      (2) Why can feature–form mismatches be hard for L2 learners?

      (3) What does L1 transfer predict about the initial L2 grammar?

      (4) State one area often predicted to be harder than narrow syntax.
