    Week 2 — Language Variation & the Learning Task #

    Anchor text: Slabakova (2016), Second Language Acquisition, Chapter 2.

    ⭐ Overview (for preview) #

    • How languages can differ (word order, agreement, null subjects, verb movement), and what exactly an L2 learner must acquire.
    • Principles & Parameters / Minimalist ideas: what is fixed vs. what varies; the role of features.
    • The learning task: initial state, transfer, input “triggers,” and how learners re-set feature values.

    🎯 Learning goals #

    By the end of this week you should be able to:

    1. Explain what “varies” across languages and why this matters for SLA.
    2. Describe the initial state and how transfer shapes early interlanguage.
    3. Derive testable predictions from specific cross-linguistic contrasts (e.g., null subjects, verb movement).
    4. Sketch a simple study that could detect parameter/feature re-setting in L2 learners.

    📖 Reading (do before Session 1) #

    • Required: Slabakova (2016), Ch. 2 (read selectively with focus on: language variation, parameters, features, examples of variation, implications for learning).
    • Optional: Revisit Ch. 1’s sections on theory → predictions → tests, as we will reuse this logic.

    Guiding questions:

    • What does it mean to “re-set” a parameter or acquire a new feature?
    • Which kinds of input are informative (diagnostic) for learners, and which are ambiguous?

    🧠 Key terms #

    variation; parameter; feature; micro- vs. macro-variation; transfer; initial state; positive/negative transfer; null subject; rich agreement; verb movement; headedness; triggers/cues; diagnostic evidence; ambiguity; poverty of the stimulus

    🔍 Core ideas #

    • What varies: Languages differ in how features are bundled and expressed (e.g., rich verbal agreement; placement of finite verb; availability of null subjects; head direction).
    • Parameters & features: Under P&P/Minimalist views, universal principles hold, while feature values (and how they’re morpho-syntactically realized) vary and must be set in acquisition.
    • Initial state & transfer: L2 learners begin with L1-based hypotheses (transfer). Early interlanguage reflects positive transfer when L1≈L2, and negative transfer when L1≠L2.
    • The learning task: Learners rely on input cues to update feature values. Some cues are diagnostic (unambiguous), others are ambiguous and slow learning.
    • Predictions: Cross-linguistic contrasts lead to early error signatures (e.g., subject omission in learners from null-subject L1s; misplacement of finite verbs by learners whose L1 has verb raising).

    🗂️ Mini-lecture outline (Session 1) #

    1) What varies across languages? #

    • Key notes:
      • Null subjects: Italian/Spanish allow phonologically null subjects; English typically does not.
      • Verb movement: French raises the finite verb over adverbs/negation; English generally doesn’t (auxiliaries do).
      • Headedness/word order: VO vs. OV patterns, adjective–noun order differences.
      • Agreement richness: Rich inflectional morphology vs. poor morphology affects syntactic options.
    • Class activity idea: Show minimal pairs (e.g., French vs. English adverb position; Italian vs. English subjects). Students label which facts would be diagnostic for an L2 learner.

    2) Principles, Parameters, and features #

    • Key notes:
      • Principles: Invariant properties of grammar (e.g., hierarchical structure, locality constraints).
      • Parameters/features: Limited options whose values vary by language (e.g., [+/- null subject], presence/absence of V-to-T movement).
      • Minimalist shift: Emphasis on features (bundling, checking, valuation) as the engine of variation.
    • Example: If L2 has rich agreement, it may license null subjects; if L2 lacks such morphology, overt subjects are required.

    3) Initial state and transfer #

    • Key notes:
      • Learners project L1 feature settings into L2 = transfer (often useful, sometimes misleading).
      • Positive transfer: Similar L1-L2 settings → faster early accuracy.
      • Negative transfer: Dissimilar settings → systematic early errors (e.g., subject drop in English by null-subject L1 learners).
    • Discussion: Identify likely transfer outcomes for your own L1 when learning English/German/French/Chinese.

    4) The learning task: input, triggers, ambiguity #

    • Key notes:
      • Diagnostic input: Clear evidence that forces a particular analysis (e.g., overt expletive “it” in English with weather verbs).
      • Ambiguous input: Compatible with multiple grammars → slower updating.
      • Prediction: Learning trajectories depend on frequency and diagnosticity of cues.
    • Activity: In groups, take one contrast (e.g., verb movement). Propose a single sentence pattern that would be maximally diagnostic for learners.

    🧪 Methods micro-lab (Session 2) #

    Goal: Turn a cross-linguistic contrast into a testable design.
    Prompt: Choose one contrast and derive a prediction + method.

    • Contrast A (Null subject): L1 Italian → L2 English.

      • Prediction: Higher subject omission in early L2 English production by Italian L1 learners vs. Chinese L1 learners.
      • Method: Elicited narrative or learner corpus analysis; code rate of overt vs. null subjects.

    • Contrast B (Verb movement): L1 French → L2 English.

      • Prediction: Misplacement of finite verb around adverbs/negation in early L2 English.
      • Method: Acceptability Judgement Task (AJT) or Elicited Imitation contrasting often position (e.g., “John often eats sushi” vs. “John eats often sushi”).

    • Contrast C (Headedness): L1 Japanese (OV) → L2 English (VO).

      • Prediction: Early word-order errors in complex VPs; slower convergence where input is ambiguous.
      • Method: Self-Paced Reading (SPR) with regions that disambiguate verb–object order.

    🧩 In-class application (Session 3) #

    Case vignette:

    • Group A: Spanish L1 learners of English (rich agreement, null subject).
    • Group B: Mandarin L1 learners of English (no rich agreement, no null subject parameter).
      Questions:
    • Which group will initially omit subjects more in English? Why?
    • What data pattern would falsify this prediction?
    • Design one classroom task that supplies diagnostic evidence for the target setting.

    ✅ Self-check (answers hidden) #

    1. Define transfer and give one example of negative transfer relevant to Ch. 2.
    1. What is a parameter/feature value? Provide one case that differs across languages.
    1. Why is diagnostic input important for the learning task?
    1. State one testable prediction about verb movement for L1 French → L2 English.
    1. How do rich agreement systems relate to null subjects in theoretical predictions?

    📝 Weekly analytical note (due before Week 3) #

    In ~300 words, pick one contrast (null subject, verb movement, or headedness). (a) State the theoretical claim, (b) derive a prediction for learners with a specific L1, and (c) outline one method (task + measure) that could detect change over time.
