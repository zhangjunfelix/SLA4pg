    Week 4 — Age, Input & the Critical Period #

    Anchor text: Slabakova (2016), Second Language Acquisition, Chapter 4.

    ⭐ Overview (for preview) #

    • What Critical/Sensitive Period claims predict for L2 acquisition and how these claims are tested.
    • How input quantity and quality shape outcomes — sometimes more than age — and how to disentangle their effects.
    • Why conclusions hinge on measurement choices (global accent vs. fine-grained morphosyntax) and design controls (AoA, LoR, education, use, dominance).

    🎯 Learning goals #

    By the end of this week you should be able to:

    1. Define Critical/Sensitive Period hypotheses for L2 and state their testable predictions.
    2. Explain how input quantity/quality and experience (LoR, use, education) confound or moderate age effects.
    3. Evaluate evidence for/against age effects based on what is measured (phonology vs. morphosyntax vs. semantics/pragmatics).
    4. Design a feasible study that separates age and input influences and identifies appropriate outcome measures.

    📖 Reading (do before Session 1) #

    • Required: Slabakova (2016), Ch. 4 (Age effects, input quantity/quality, “nativelikeness,” methodological caveats).
    • Optional: Skim Ch. 12’s brief overviews of methods to anticipate Week 11.

    Guiding questions:

    • What, exactly, would count as falsifying a strong Critical Period claim?
    • Which measures are most sensitive to age (accent? inflectional morphology? lexical semantics?) and why?

    🧠 Key terms #

    Critical Period (CPH); Sensitive period; Age of Arrival (AoA); Length of Residence (LoR); ultimate attainment; nativelikeness; input quantity; input quality; dominance; literacy/education; diagnostic evidence; confound; moderation; global vs. local measures

    🔍 Core ideas #

    • Not one outcome, many: Age relates differently to phonology (large age effects), morphosyntax (mixed), and semantics/pragmatics (often learnable with input).
    • Input matters: The amount (quantity) and informativeness (quality/diagnosticity) of input can attenuate age effects; poor or ambiguous input slows attainment.
    • Operationalization is destiny: “Nativelikeness” depends on what you measure (accent ≠ grammar ≠ processing). Global ratings and local diagnostics can diverge.
    • Design before verdict: Strong claims (e.g., maturational closing) require controls for use, education, SES, literacy, motivation, and task demands.

    🗂️ Mini-lecture outline (Session 1, 45 min) #

    1) What do Critical/Sensitive Period claims predict? #

    • Key notes:
      • Strong CPH: maturational window closes → discontinuity in outcomes by AoA.
      • Sensitive period: continuous decline with age, but learning remains possible.
      • Predictions: later AoA → lower ultimate attainment holding input constant; the shape (break vs. slope) is empirical.
    • Class spark: One-minute write: Which skill in your L2 feels most “age-locked”? Why?

    2) Evidence patterns & measurement choices #

    • Key notes:
      • Phonology typically shows robust age effects; morphosyntax shows mixed results depending on measure (accuracy vs. online processing).
      • Global vs. local: “Sounds native” ≠ “uses inflection/article semantics native-like.”
      • Task effects: time pressure (online) reveals processing costs despite near-native offline accuracy.
    • Think–pair–share: Identify a study conclusion that would flip if a different measure were used.

    3) Input quantity/quality and design controls #

    • Key notes:
      • Quantity (hours/years, richness of exposure) and quality (diagnostic cues, literacy, classroom focus on form) can mediate age effects.
      • Control for LoR, current use, education, and dominance; report exposure profiles.
    • Quick design pitch: In pairs, propose one control you’d add to an AoA study and say why it matters.

    Pacing note: Three topics x ~12 min each + 9 min discussion fits a 45-min session.

    🧪 Methods micro-lab (Session 2, 45 min) #

    Goal: Separate age from input in a simple, testable design.

    1. Define outcome (choose ONE):

      • Global accent rating • inflectional morphology accuracy • article semantics • scalar implicature judgments.

    2. Groups (match on input where possible):

      • Early/AoA≤7 vs. Late/AoA≥15; match LoR, current L2 use, education.

    3. Prediction (pick the right shape):

      • Discontinuity at a boundary (strong CPH) or gradual slope (sensitive period).
      • Specify which module should show the effect (e.g., phonology > morphosyntax).

    4. Measures & controls:

      • Outcome measure + at least two covariates (LoR, use, literacy).
      • Plan power (rough N) and analysis (e.g., regression with AoA, covariates).

    5. Report (2–3 lines):

      • Hypothesis, key prediction, primary measure, and what result would falsify your claim.

    🧩 In-class application (Session 3, 45 min) #

    Case vignette (small-group analysis → whole-class synthesis)

    • Group A: AoA 18, LoR 12 yrs, daily L2 use at work, high literacy; Outcome: near-native morphosyntax online but accented speech.
    • Group B: AoA 9, LoR 12 yrs, low L2 use, limited literacy; Outcome: native-like accent but unstable article semantics.

    Questions:

    1. Which results follow CPH expectations, and which highlight input effects?
    2. What additional data would you collect to adjudicate?
    3. Design one teaching intervention targeting the weaker domain in each group (focus on form? input enhancement? tasks?).

    ✅ Self-check (answers hidden) #

    1. State one falsifiable prediction of a strong CPH for L2.
    1. Give an example where measure choice changes the age conclusion.
    1. Define input quality and give a diagnostic example.
    1. Name two covariates that must be controlled in AoA studies.
    1. What result would favor a sensitive-period over a strict CPH?

    📝 Weekly analytical note (due before Week 5) #

    In ~300 words, choose one outcome domain (phonology, morphosyntax, or semantics/pragmatics). (a) State a CPH or sensitive-period claim for that domain, (b) derive a prediction that controls for input/use, and (c) outline a measure + analysis (variables, covariates, expected pattern).

    🧭 Preview of Week 5 #

    We compare acquisition contexts — simultaneous bilinguals, early L2, adult L2, heritage speakers, attrition — and ask what transfers, what restructures, and how context reshapes predictions.
